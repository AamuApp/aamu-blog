This is where you configure the public booking page for the project.</p><p>The exact settings may vary by workspace, but the important options are the same kind of things you would expect from a scheduling tool:</p><ul><li><p>the booking link,</p></li><li><p>the event type or meeting type,</p></li><li><p>available days and times,</p></li><li><p>duration or time slots,</p></li><li><p>how unavailable times are shown, and</p></li><li><p>whether the booking should create a video meeting.</p></li></ul><p>Once the settings are ready, copy the event booking link and share it with people who should be able to book time with you.</p><h2>The booking page</h2><p>The public booking page shows available times in the visitor’s timezone.</p><p>The visitor chooses a suitable time, enters contact details, and confirms the booking. The page can show unavailable days or times as disabled, so the person booking does not need to ask which slots are possible.</p><h2>What happens after someone books?</h2><p>A confirmed booking creates a task with details, dates, assignment, status and comments.</p><p>For video bookings, Aamu can also create a meeting linked to the task.</p><p>You can then use the task like any other Aamu task:</p><ul><li><p>add notes before the call,</p></li><li><p>assign someone to handle it,</p></li><li><p>comment internally,</p></li><li><p>link related docs or customer information,</p></li><li><p>create follow-up tasks, or</p></li><li><p>sync task timing to an external calendar when your setup supports it.</p></li></ul><h2>When Aamu is a good Calendly alternative</h2><p>Aamu Event Booking is a good fit when you want scheduling to connect to team work. For example:</p><ul><li><p>customer calls that need follow-up tasks,</p></li><li><p>product demos that should create an internal work item,</p></li><li><p>support calls where notes and next steps matter,</p></li><li><p>consultation slots connected to a project,</p></li><li><p>interviews or onboarding meetings, and</p></li><li><p>video meetings that should be created automatically.</p></li></ul><p>If all you need is a standalone scheduling page with no connection to the rest of your work, a dedicated scheduling tool may be enough. If you want the booking to become part of the project workflow, Aamu makes more sense.</p><p>Calendly’s <a target="_blank" rel="noopener noreferrer nofollow" href="https://calendly.com/pricing">plan comparison</a> also includes team scheduling and lead routing on Teams, and payment connections on Standard. It is worth evaluating when those specialized booking requirements are central. Check each behavior in Aamu before replacing an existing scheduling setup.</p><h2>A practical setup</h2><p>A simple setup can look like this:</p><ol><li><p>Open the project settings.</p></li><li><p>Go to Tasks and Event Booking.</p></li><li><p>Configure the event type, duration, availability, and meeting behavior.</p></li><li><p>Copy the public booking link.</p></li><li><p>Share the link on your website, in email, or with a specific customer.</p></li><li><p>When someone books, review the created task in Aamu.</p></li><li><p>Use the task and meeting for preparation, the call itself, and follow-up.</p></li></ol><h2>Tips</h2><ul><li><p>Use a clear event name, such as "15-minute intro call" or "Product demo".</p></li><li><p>Keep the duration realistic.
