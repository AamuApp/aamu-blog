<p><strong>Short answer:</strong> How Aamu.app Event Booking works as a Calendly alternative with booking pages, availability, project meetings, and connected follow-up.</p>
<p>Aamu Event Booking lets visitors choose a time through a public booking link. A confirmed booking creates a project task and, when configured, a video meeting.</p><p>The basic idea is simple: you configure an event booking page, share the booking link, and when someone books a time Aamu creates the related work item for you. If the event type uses video, Aamu can also create the meeting.</p><h2>What Aamu replaces</h2><p>A booking can become:</p><ul><li><p>a task in the project,</p></li><li><p>a scheduled event your team can track,</p></li><li><p>a video meeting when the event type calls for it, and</p></li><li><p>a piece of work that can live near docs, comments, tasks, and follow-up.</p></li></ul><h2>Where to configure Event Booking</h2><p>Open the project settings and go to the Event Booking settings under Tasks. This is where you configure the public booking page for the project.</p><p>The exact settings may vary by workspace, but the important options are the same kind of things you would expect from a scheduling tool:</p><ul><li><p>the booking link,</p></li><li><p>the event type or meeting type,</p></li><li><p>available days and times,</p></li><li><p>duration or time slots,</p></li><li><p>how unavailable times are shown, and</p></li><li><p>whether the booking should create a video meeting.</p></li></ul><p>Once the settings are ready, copy the event booking link and share it with people who should be able to book time with you.</p><h2>The booking page</h2><p>The public booking page shows available times in the visitor’s timezone.</p><p>The visitor chooses a suitable time, enters contact details, and confirms the booking. The page can show unavailable days or times as disabled, so the person booking does not need to ask which slots are possible.</p><h2>What happens after someone books?</h2><p>A confirmed booking creates a task with details, dates, assignment, status and comments.</p><p>For video bookings, Aamu can also create a meeting linked to the task.</p><p>You can then use the task like any other Aamu task:</p><ul><li><p>add notes before the call,</p></li><li><p>assign someone to handle it,</p></li><li><p>comment internally,</p></li><li><p>link related docs or customer information,</p></li><li><p>create follow-up tasks, or</p></li><li><p>sync task timing to an external calendar when your setup supports it.</p></li></ul><h2>When Aamu is a good Calendly alternative</h2><p>Aamu Event Booking is a good fit when you want scheduling to connect to team work. For example:</p><ul><li><p>customer calls that need follow-up tasks,</p></li><li><p>product demos that should create an internal work item,</p></li><li><p>support calls where notes and next steps matter,</p></li><li><p>consultation slots connected to a project,</p></li><li><p>interviews or onboarding meetings, and</p></li><li><p>video meetings that should be created automatically.</p></li></ul><p>If all you need is a standalone scheduling page with no connection to the rest of your work, a dedicated scheduling tool may be enough. If you want the booking to become part of the project workflow, Aamu makes more sense.</p><h2>A practical setup</h2><p>A simple setup can look like this:</p><ol><li><p>Open the project settings.</p></li><li><p>Go to Tasks and Event Booking.</p></li><li><p>Configure the event type, duration, availability, and meeting behavior.</p></li><li><p>Copy the public booking link.</p></li><li><p>Share the link on your website, in email, or with a specific customer.</p></li><li><p>When someone books, review the created task in Aamu.</p></li><li><p>Use the task and meeting for preparation, the call itself, and follow-up.</p></li></ol><h2>Tips</h2><ul><li><p>Use a clear event name, such as "15-minute intro call" or "Product demo".</p></li><li><p>Keep the duration realistic. Shorter booking slots work well for quick calls; longer ones are better for demos and onboarding.</p></li><li><p>Add enough buffer in your availability so bookings do not create a packed calendar.</p></li><li><p>If the meeting needs preparation, use the created task to collect notes before the call.</p></li><li><p>If the booking often leads to follow-up work, create those follow-up tasks directly from the original task.</p></li></ul><h2>Related articles</h2><ul><li><a href="/blog/posts/video-meetings-feature-overview/">Video Meetings - feature overview</a></li><li><a href="/blog/posts/aamuapp-as-an-ai-workspace-alternative-to-notion-ai-slack-ai-jira-and-zendesk/">Aamu.app as an AI workspace alternative to Notion AI, Slack AI, Jira, and Zendesk</a></li><li><a href="/blog/posts/aamuapp-vs-asana-tasks-and-shared-context/">Aamu.app vs Asana: tasks are better when they remember why they exist</a></li><li><a href="/blog/posts/aamuapp-vs-intercom-support-and-product-context/">Aamu.app vs Intercom: support should not need a passport to reach product</a></li><li><a href="/blog/posts/company-brain-in-aamuapp-ai-across-your-workspace/">Company Brain in Aamu.app: AI across your workspace</a></li></ul>
